## 解释边界

- 原生凭据隔离开发成功，不等于所有搜索、图像、压缩等辅助能力都已经验证，也不等于真实账户额度刚好归零的场景已直接发生。
- 桌面测试使用应用随附二进制的独立 app-server，不将程序接口证据冒充点击了当前宿主 UI。
- `turn.completed` 不能单独证明任务完成。Pro 无工具续接也返回 completed，独立 CLI 检查仍然正确判为失败。
- 部分 stderr 出现本机 WebSocket 426 后，客户端使用同一环回地址的 HTTP 流继续；不等于自动切回原生推理。
- `chatgpt-web/pro` 表示桥接选择的网页 effort。此版本内部路由标识是 gpt-5.6-sol，没有独立的远端权重身份凭证，不能把它直接称为 GPT-6 Pro。
- 没有发布真实账号、浏览器档案和原始会话；别人必须在自己的环境复验。
